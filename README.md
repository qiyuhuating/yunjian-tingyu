# 云笺听雨 · 0.0.1

为自己留一处能聊天、听歌、写日记的小天地。个人使用的 Android 陪伴应用；无需登录，界面与资源随 APK 打包，聊天、附件、角色卡和设置保存在设备本地。调用 AI 服务时仍需要网络和你自己的 API Key。

[下载 0.0.1 系统隔离 APK](outputs/云笺听雨-0.0.1-系统隔离版.apk) · [安装说明](outputs/APK安装说明.md) · [签名与完整性报告](outputs/云笺听雨系统隔离签名与完整性报告.md)

## 固定核心与角色资料

所有角色聊天模式共享固定的核心 system；核心可在设置中明确编辑、保存或载入原始版本；角色卡、世界书、个人资料、历史、摘要和实时通话上下文单独发送。用户最新明确要求优先于可编辑预设，角色资料不能改写实际系统字段。支持成年人自主、同意的性相关讨论与正当创作及政治、社会争议讨论；未成年角色互动保持非性化。事实摘要使用原有独立整理器提示词，不承担角色聊天。实现与验证见 [核心提示词隔离说明](docs/核心提示词隔离说明.md)。

默认自动使用当前模型的最长可用窗口，优先读取服务商元数据，再采用有来源的官方预设。支持 1M 的模型按 1M 配置，为正文和思考预留空间；未知上限显示 32K 保守回退，可手动填入实际限制。移除了原有几十条历史、100 条请求和 400K 文字的限制。

## 群聊与界面

多个角色独立接话，默认短消息，日常问题可分多条回答，重要解释可更长，保留人设口吻，不写旁白、动作或环境。普通话题默认最多两位成员接话，可修改人数；后续角色无需凑回答。支持 @、引用、自然等待、逐条发送与取消，等待时还能继续发文字。群名与成员管理、收藏和群记忆保留；单人剧情预设保留。

软件桌面图标与内置 Via 的浏览器入口采用你提供的笑脸耳机云朵原图，透明边缘保留，按图形边界居中。

聊天使用一层标题与明确返回路径，主要操作 48px、图片预览再保存、错误状态可见；横屏输入栏和暗夜层次已验证。通话入口进入真实 Realtime，文字朗读另行提供。私人社区与云币仍是有明确标识的本地虚构互动；日历关闭应用后无系统闹钟。

## 每位朋友的记忆与能力

默认每四条用户消息，参与回复的角色通过当前模型整理自己的记忆；记录与原话证据、来源、游标均保存在本机，可关闭或调整频率。最新更正保留修订历史，较旧会话不会回写覆盖新偏好；用户编辑的记忆自动保护。原聊天、相关召回和阶段摘要继续保留，动态资料放在缓存前缀后。

角色卡决定身份、口吻、爱好和教学偏好，编程、数学、分析与创作能力仍由接入模型提供。默认中文，随用户当前语言或明确要求切换；技术任务保留必要步骤与代码。文字代码可完整保存，未接生图服务时可交付 HTML/CSS 等绘图代码，不冒称已生成或执行。

任意扩展名附件可发送、保存和下载，单文件 200 MB；常用文本、源码、DOCX/PPTX/XLSX/ODT、PDF 文字和 ZIP 内文字可本地解析，PDF worker 随 APK 提供。解析、解压与截断限制均明确提示；无法解析的二进制、音视频、加密文档和扫描件不会假称理解。图片理解须接入支持视觉的模型。

设计来源、实现计划与能力边界见 [群聊与角色记忆调研](docs/群聊与角色记忆调研.md)。

## 复现检查

需要 Node 22.13+、Python 3、Git。以下命令从仓库根目录执行：

```sh
npm ci --prefix outputs/mori-phone
npm ci --prefix work/qa
npx --prefix work/qa playwright install chromium
python work/check-release.py
node outputs/mori-phone/node_modules/vite/bin/vite.js preview --config outputs/mori-phone/android-web/vite.config.ts --host 127.0.0.1 --port 5175 --strictPort
```

在另一个终端执行 `python work/check-browser-release.py`。六组当前浏览器检查可使用 Playwright 安装的 Chromium；已有浏览器可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`。历史 QA 脚本保留了当时的路径、端口和页面结构，只作开发记录，需按对应版本调整后运行。

重新生成前端资源：`cd outputs/mori-phone` 后执行 `node node_modules/vite/bin/vite.js build --config android-web/vite.config.ts`。Android 构建按 [原生构建说明](outputs/android/README.md) 执行；Windows 请在 ASCII 路径下构建。APK 完整性验证脚本保留了原构建环境路径，迁移时需替换 SDK、JDK、未签名 APK 和证书记录路径。仓库不含私有签名备份，签名文件仍由机主在本机保管。

当前证据包括 103 项核心检查、TypeScript 检查和 6 组浏览器回归。模型调用使用测试响应；另在 Android 15 / WebView 124 模拟器完成实际安装、内置 Via 浏览/返回与本地日记重启持久化、真实系统文件选择器和离线 PDF 读取验证。未完成真机、真实模型、真实通话与低内存回收的验收。不能将这些检查解释为绝对无缺陷。

## 内置 Via 与首页回退

浏览器直接进入随 APK 合入的 Via 7.3.3。首页恢复用户参考图的原排版与四栏插画导航；Android 三键栏、Via 顶部状态栏在应用内隐藏。实现、来源与模拟器证据见 [自然群聊与内置Via说明](docs/自然群聊与内置Via说明.md)。
