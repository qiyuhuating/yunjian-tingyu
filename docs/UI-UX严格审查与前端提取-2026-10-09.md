## 决策摘要

**必须保留：原有字体及字族/回退链、插画、云朵与桌宠、纸面/玻璃质感、浅色/暗夜主题、四栏 Dock、手机框架、现有功能与用户数据。**

目标不是「做得更热闹」，而是使每个页面的操作路径更可读、更稳定、更符合「优雅、克制、可爱」。强制要求不引入新字体、不替换中文回退、不更改 Source Serif 4 字体文件、不降画质、不批量重新绘制资源、不改变角色提示词/记忆语义、不改动业务数据格式。

## 二、视觉不可变约束

- **字体完全不变**：所有现有 `font-family`、`@font-face`、Source Serif 4 WOFF2/TTF、中文后备字族以及已经存在的代码等宽栈保持原状。可以调间距、布局及非字族层级，但不能「换系统字体」或悄然统一为另一字族。
- **色彩方向保持**：柔和灰蓝、纸面白、温柔粉色点缀和暗夜中性表面不改色相风格；对比度不足处只局部提高信息文本与背景的可辨性，需视觉差分审批。
- **克制的可爱**：保留云朵与壁纸、桌宠、手绘按钮。每屏只设一个视觉主角，已存在的装饰不再叠加眩光、渐变、大面积贴纸或悬浮菜单。
- **统一而非同质化**：按钮与卡片圆角、阴影、边框、间距应来自一套 token，但首页的生活气息与设置/角色编辑的高密度工具信息必须保持区别。
- **动效有意义**：交互确认与轻微反馈可以保留；关闭 `prefers-reduced-motion` 时非必要转场及持续绘制需真实停止或降频；禁止仅为了“灵动”添加动画。
- **保留功能归属**：角色卡仓库是可复用模板，聊天角色是实例，世界书是可独立编辑的背景，记忆是会话衍生信息。视觉必须通过名称、位置和按钮文案防止概念混淆。

## 三、页面精修规格

### 3.1 首页（Home）

保留四栏 Dock、现有日期/一起听/小纸条/插画入口及桌宠。首屏由「欢迎氛围」过渡到「上次交谈」，**只调整既有卡片的信息优先级**，不增加第五个 Dock。首开与已配置用户采用不同的补充说明。默认状态浅色不被系统主题强行覆盖。

### 3.2 私聊与群聊

消息区仍以角色头像、称呼、简洁气泡和可见操作为主。群里模型、人物身份或失败信息应在需要时可得，但不能让每条日常消息被技术状态包围。消息加载、失败重试、正在回应、后台记忆分别展示。多图、语音、文件、长代码和引述用一致的附件布局；超过窗口时不撑宽消息列。消息读取位置以锚点保留，不强行自动跳底。

### 3.3 角色卡仓库与编辑

仓库优先呈现名字、头像、分类与更新状态；搜索/筛选/收藏保留，减少重复的技术介绍。编辑区依次是「基本资料」「人物与开场」「世界书」，作者协议字段与高级互操作折叠。区分「保存到卡库」「从卡库创建角色」「更新某个已存在角色」，后两项必须出现对象与影响说明。切换对象时清楚提示未保存草稿归属。

### 3.4 世界书

默认展示可检索列表；点击条目进入编辑；导入/导出和命中调试作为次级入口。常驻/条件触发/归属/启用清晰可查，复杂条件放进折叠。必须优先补草稿与离开守卫（UX-01）。

### 3.5 设置、连接、备份

任务顺序为 **服务商 → Key → 模型 → 保存 → 测试**。保存不是测试，测试可能产生计费。把聊天/语音/外观/本地数据组成可扫读分组；「破坏性恢复备份」应突出影响而非强调色彩。备份及恢复继续遵守现有密钥隔离。

### 3.6 其他工具

24 个入口仍必须可到达，但重复的虚拟社交、商城与小工具在「全部应用」中可分组；不擅删功能或数据。减少长说明占位而不隐瞒虚拟性质。所有删除和数据覆盖都要具备确认或可撤销路径。

## 五、可执行的验收矩阵

1. **视觉**：浅色/暗夜 × 320/360/390/430/768/1440px × 100%/200% 字体；全部核心视口无非预期横向溢出、内容遮挡和输入不可达。使用同设备同条件截图基准，变更逐处解释而不是盲目追求像素一致。
2. **字体与资源**：`Source Serif 4` 所有字体文件、中文回退、背景与所有 sprite 裁切映射 SHA 或 CSS 字族规则与基线一致；只有明确授权的布局和标注大小变化。
3. **对比与触控**：普通文本对比度目标至少 4.5:1、非文本控件边界至少 3:1；主要触控区目标 44–48 CSS px，例外列入明细；焦点环对浅色/暗夜清晰。不能只以历史「十个点通过」等同全站覆盖。
4. **流程**：首次启动→连接→测试→私聊；导入角色卡→保存到仓库→两次应用为独立角色；世界书导入/编辑/命中预览；群聊各自模型；语音及文件发送；离开/刷新/中断/重试/删除/撤销/完整备份。
5. **性能**：1k/5k/20k 消息和 1k 世界书；分开测首次打开、回到已读位置、输入延迟、滚动主线程长任务、峰值内存；桌面 Chromium 统计不能替代低端 Android 真机。
6. **系统边界**：Android 返回、IME 软键盘、窗口 Insets、横屏、后台恢复、杀进程重启、低空间保存失败、WebView 媒体权限、无网络/无 Key/模型不存在。重复从主界面进入不同编辑器不能串草稿。
7. **发布**：TypeScript、既有 243 项范围对应测试、Web 构建、Android Java、当前分支浏览器 UI/UX 回归、新旧数据迁移、原 APK 同证书覆盖升级与备份恢复；没有原签名不能将 unsigned APK 宣称为正式可安装包。
