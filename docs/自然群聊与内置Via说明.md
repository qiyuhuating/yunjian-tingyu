# 云笺听雨 0.0.1 · 自然群聊与内置 Via

## 计划、执行、验证

1. 群聊默认自然短消息，允许日常问题分多条回复、必要解释更长。验证实际请求预算、分泡存储与旁白格式拒绝。
2. 合入用户提供的 Via 7.3.3，让浏览器入口直接调用同一 APK 的 Via Shell。验证安装、网页链接、系统返回、回到首页、网页与本地桥接隔离。
3. 首页恢复用户参考图的原排版、留白和四个插画导航入口；隐藏 Android 三键栏及 Via 系统状态栏。验证参考视口 390×844，短视口可滚动到原导航；模拟器截图复核。
4. 沿用 0.0.1 与原签名，生成源码包、逐文件介绍与摘要，再更新私密 GitHub，等待 CI 成功并验证发布下载。

## 群聊

每个角色只以自己身份发言，不代写他人、旁白、动作或环境。不要求用户每轮指定长度与口吻：系统约束和角色卡继续负责。默认短，有需要时可自然分开说几句；关键原因、重要事项、必要步骤或容易误解的问题允许展开。没有固定“一至三句、每句60字”或384 Token的群聊限制。输出会拆成独立聊天气泡并逐条保存。

普通消息一轮八条、单条1200字符、总计6000字符只是错误输出的资源上限，不是日常回复目标。明确的代码资料允许多行及最多18000字符，以免截掉可用实现；文字按原样显示和保存，不执行代码。保留真人日常括号、情绪及普通数学符号；拒绝剧情格式和无效结构。无法读取的输出只做一次纠正重试，不把坏格式直接保存成群消息。@、轮换、独立角色上下文、群摘要与群记忆沿用已验证实现。

## Via 来源与合包

机主提供的 `via-release-cn.apk`：Via 7.3.3，原包名 mark.via，原内部版本号20260823。原件SHA-256：`c64c71458df03ef98bac3acdecafcab6bf9fd930a53fca5d72b284383ed03985`。

原件保存到 `outputs/android/vendor/`，不会冒称开源代码或浏览器SDK。[Via官方仓库](https://github.com/tuyafeng/Via)公开的是翻译资源。构建通过固定摘要、原资源ID和二进制合包，把云笺听雨入口、字体、资源与第二份DEX加入包中。Via原DEX只将文件共享authority作等长修改，并更新DEX摘要；校验字符串表顺序，避免Android拒绝加载。原件仍原样保留。

浏览器入口直接进入包内 mark.via.Shell；网页、搜索、历史和页签由真正 Via 处理。浏览器返回按钮有独立空间，点击回到原本的本地首页，不打开独立 Via 或其他浏览器。Via首次使用保留原有条款页。可与独立 Via 同时安装；浏览器的文件共享标识和应用启动标识不会冲突。

Via网页无法使用本地主界面的 Android / NativeHTTP 桥接；没有把外部网址装进持有Key请求桥接的首页WebView。随包关闭Via遥测采集配置，移除广告ID、安装归因与查询所有应用权限。浏览器的书签、历史与下载记录保存在应用私有目录，属于Via自己的数据库，不包含在小手机ZIP备份中。

## 界面与兼容

首页按用户最后参考图恢复原样，原有绘图、Source Serif 4和浅暗主题保留。Android系统三键栏在应用内隐藏；Via顶部系统状态栏隐藏。Android仍允许用户用边缘手势临时显示系统控制。短屏可滚动主页内容到四个原导航入口；参考尺寸保持原样。

小手机需要WebView120或更新版本；旧内核显示更新提示，关闭提示也不会触发空WebView生命周期错误。当前验收使用Android15 / WebView124，另以Android11 / WebView83验证兼容提示。测试使用可丢弃模拟器，不操作机主的物理手机。

## 验收范围

103项核心检查、严格TypeScript和五组浏览器回归。原生模拟器验证包括原四栏的实际可见范围、内置Via的真实HTTP页面、链接与返回历史、独立返回入口不遮地址栏、网页桥接隔离、日记重启持久化、独立Via共存及旧内核提示。详细结果、截图与安装包摘要放在outputs。没有真实API Key、真实通话、麦克风或物理设备验收，不能据此声称所有模型绝不写旁白、绝对无遗忘或绝对无缺陷。
