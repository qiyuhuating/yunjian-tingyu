# 云笺听雨 · UI/UX 与群聊审视

本轮按「计划—执行—验证」完成，保留 0.0.1 版本名，Android 内部版本号增至 4。默认浅色、安静的首页、插画按钮、Source Serif 4 和本地数据方案均保留。

## 设计依据与修复

参考 [UI UX Pro Max 官方 skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md) 的可访问性、触控、性能与交互清单，以及 [腾讯 WeUI](https://github.com/Tencent/weui) 的移动消息界面习惯。该 skill 当时未安装，因此读取官方项目；没有照搬它给营销网站推荐的字体或 Hero 布局，没有复制社区聊天记录。消息例句由本项目编写，不声称是微信聊天数据统计。

| 发现的问题 | 已实施的修复 |
| --- | --- |
| 聊天详情有两层标题，返回路径含糊 | 留一层角色/群标题；独立返回列表与首页；系统返回先关闭图片或通话面板，再返回应用 |
| 小图标难点，收藏依赖悬停 | 主要聊天操作 48px；消息操作 44px；收藏进入触控菜单；收藏页提供可见取消按钮 |
| 群头像受旧 flex 规则影响挤歪 | 独立四宫格头像，固定行列与尺寸；小屏明确收缩，不抢标题宽度 |
| 群回复只有剧情式长段，始终前几位发言 | 独立手机群聊规则，轮换覆盖全部成员，默认两位接话；@ 指定成员、@所有人；各成员单独调用模型 |
| 群成员的回复被误当作当前角色自己的历史 | 消息保存 senderId；其他角色的话作为有姓名的群上下文，旧数据仍可读取 |
| 摘要无法区分多位角色 | 群摘要原文标注实际发言者；群内手动记忆限定群作用域，其他群和私聊不读取该群记忆 |
| 重试可能重复已经完成的角色回复 | 成功的消息先保存；取消保留已有内容；重试继续剩余角色；失败标签可见，不把半段数组保存为消息 |
| 图片点击直接触发导出 | 可放大预览的原生 dialog；明确保存按钮；Esc / 系统返回关闭并恢复焦点 |
| “短对话”名称与实际行为不符 | 改为“只看最近 6 条”，原记录保留；完整视图仍分批加载旧消息 |
| 纸条、动态、桌宠短文可能带入聊天选项标签 | 新增正文生成模式；与剧情/接话规则分开，清理聊天选项标记 |
| 计时＋朗读被表现成通话 | 删除这条表现；通话按钮直接进入真实 OpenAI Realtime 接口；文字朗读独立标明 |
| 横屏固定手机壳导致输入栏跌出屏幕 | 矮视口切换满屏布局；输入与主要操作保留在可见区域，长文字换行 |

浅色使用柔和的纸面层次，暗夜沿用已验证的中性深灰表面与清晰文字，群聊不铺背景图。连续短消息减少重复姓名/头像，时间按间隔分组。图片、朗读、键盘焦点和错误反馈使用同一套表面与圆角。没有为了填满首页增加卡片。

## 群聊的实际行为

每位 AI 角色仍有独立的人设、模型上下文和发言身份。年龄、口吻与长度偏好从角色卡及系统默认读取，用户不用每轮指定；不把全部角色限定为成年。角色卡与命中的世界书进入实际 API 系统提示词，应用内用户最新明确要求优先。聊天原文、摘要和附件仍是记录资料；角色卡后置资料也会采纳称呼、句式等偏好，群聊的纯消息格式与硬长度上限优先。通常每条 5—40 字，硬上限每条 60 个 Unicode 字符，一次 1—3 条、最多 180 字，分成真正的消息泡。可简单回应，也可把信息说清；不要求每条带语气词或提问。

群聊覆盖剧情预设中的旁白、动作、环境与内心描写规则，不显示接话选项，不替其他人发言。格式不正确或常见舞台标记会尝试修正一次；仍不合格会显示失败并保留此前记录。格式验证不是完整的自然语言识别器，无法保证每个外部模型都绝不会生成未带标记的叙述性句子，需要实际 Key 验证其人设与口语表现。

群名与成员管理、点击姓名插入 @、导出、收藏和群记忆都有实际数据操作。群发言沿用重复惩罚设置，并只与该成员近期回复比较；固定人设与群名单保留在稳定系统前缀中；角色卡要求与命中世界书随后进入系统设定，日期、新消息、摘要在记录部分，避免每轮改动缓存前缀。世界书命中集合变化会影响其后续上下文的缓存复用；固定人设和默认规则排在它之前，摘要和记忆不会写入固定系统前缀。命中率仍取决于服务商和实际会话，未虚报收益。

## 功能真实性核对

| 功能 | 本轮证据与边界 |
| --- | --- |
| 24 个应用入口 | 浏览器逐一打开，无空页面、脚本错误或横向溢出；不等于所有子流程已穷尽 |
| 群聊、角色、附件、记忆、收藏、草稿 | 真实本地存储、刷新恢复与取消重试验证；网络响应使用 fixture |
| 通话与朗读 | 通话入口真实 Realtime；设备 TTS / 云端朗读保留；未测真机麦克风、真实通话或音质 |
| 一起听 | 有效本地 WAV 实际播放，LRC 原歌词随进度；点击桌宠打断情绪通过；跳转服务交给外部音乐应用，不声称读取其歌词 |
| 天气与浏览器 | 天气真实发起请求并使用返回数据；收藏网址交给外部浏览器；测试上游响应受控 |
| 论坛、朋友圈、微博、小直播间 | 有真实本地内容生成、发布、点赞等操作；它们是标明的私人虚构社区/剧情，不是真实公共社交或直播服务 |
| 云币、工作、礼物、红包、转账 | 本地积分、账目和互动，非真实金融；购买、扣款、送礼持久化通过 |
| 日历提醒 | 明确标注应用打开时生效；关闭应用后没有系统闹钟，不包装为后台通知 |
| 文件识别 | 可以保存/导出文件；模型只读取实际解析出的文字或可用图片，不声称解析任意压缩包、加密文档 |

未发现本轮审阅入口中仅用成功提示冒充数据写入的操作。已移除误导性的通话表现；虚构互动与外部服务能力的范围已明确。这不是“全软件无任何缺陷”的保证。

- 新 APK v2/v3、同一签名证书、4 字节对齐、CRC、24 个资源 SHA-256 以及所有源资产逐字节一致性通过。
