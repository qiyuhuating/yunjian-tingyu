## 本轮新增验证

1. 摘要请求期间修改、删除早期来源或改变附件引用，拒绝提交旧摘要；请求前固定哈希，提交时重新比较。
2. 自动记忆只有 ID 而缺原文证据时不召回；正确处理 sourceAt=0，正文证据或时间改变时失效。
3. Agent 请求期间源文件同版本静默改变，结果不得进入报告、聊天或 completed 列表。
4. 停止只移除本线程自动意图；其他线程仍可执行，in_flight 回执保留未知结果。
5. 群聊两角色之间中断，仅恢复尚未完成角色，不重复已落盘回复。
6. 原生媒体的暂存资产随最终回复提交；失败不得把回执标为 completed。
7. 真实 Chromium IndexedDB：消息与排队意图统一回滚、外部备份清空旧自动发送意图。
8. 真实 Chromium IndexedDB：生成 Blob、正文、媒体消息、回执成功共同落盘，强制事务中止后共同回滚。
9. 页面冷重载后读取实际落盘记录：恢复合法队列，未知 POST 仍不可自动重放。

本地严格核心测试 260 项、媒体/P0 19 项、真实 Chromium 存储 19 项已通过；严格 TypeScript 通过。整合提交 bafd15e5d958014d206ad55090faf8a6ab34c33b 需再由完整 GitHub Actions 运行文件清单、生产网页、全部浏览器回归、Android Java 编译及签名候选构建。最终结果以实际 Actions 日志、sourceCommit 和 candidate-check.json 为准。

## 保留的边界

- APK 签名证书、包身份、版本递增、zipalign、ZIP/资源一致性可由 CI 核验；安装后的真实 Android 网络、VPN/Fake-IP、旧版本数据升级、低内存与长时运行仍没有本轮实机证据。
- 哈希证明输入输出一致性，不证明模型观点正确或执行过代码。
- 当前 Agent 是受限会话文本工具与顺序审阅；通用沙盒代码执行、项目级索引、成本硬预算、完整回合配置快照和分域性能优化仍未完成。
- 源码合并与签名候选交付不等于正式稳定发布；不覆盖旧 Release。发布前继续按 issue #15 补实机证据。
