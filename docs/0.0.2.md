## 合并取舍

- #1：保留实际录音、多模态适配、壁纸、IndexedDB v3 与无损 WebP，并纳入后续媒体解码校验、完整 PCM 合并、断流失败、OpenRouter 参数能力、历史姓名前缀和异步草稿修复。

- #3：原文完整覆盖的 AI 人物/世界拆分、世界书引擎、来源记忆、角色卡模板仓库及编辑界面。
- #4：模板去重、数量/字节预算、修订保护、复制、删除和备份头像映射。

两个分支对自动附件清理有冲突，最终保留原件，避免销毁未提交的新引用；备份仍只收录实际被状态引用的附件。删除角色或库卡不会自动破坏原附件。编辑器同时保留切换卡片隔离与提交快照保护；卡库保存期间的新输入保持草稿，更新修订号，可刷新后继续保存。没有换成另一套平行的角色卡仓库。

四份原提交全部保留在 Git 历史中，通过带双父提交的最终整合继承 #1 的后续改动，再以合并方式进入 main，不压平或改写分支历史。
