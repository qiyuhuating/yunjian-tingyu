# 云笺听雨 0.0.1 · 本机记录与接口边界修复

## 范围与工作流

机主明确授权修复自有软件。机主要求停止红队测试后，停止新增攻击路径研究和实际突破；本轮后续工作只处理已发现问题，运行既有功能回归及本地边界断言。无需 Daybreak 或其他外部服务。真实 Key、私人聊天、物理手机均未作为测试资料；模拟器与虚拟服务商地址用于验收。

版本名保持 0.0.1，内部版本递增 7，沿用原证书。原核心系统提示词常量不修改，保留用户在设置里的主动编辑入口。

## 发现、核实与修复计划

| 项目 | 原行为及证据 | 修改与验收标准 |
| --- | --- | --- |
| 备份改变本机连接和核心提示词 | 修复前读取虚拟 JSON 备份，stageBackup 后 wireRequest 目标变为 untrusted.fixture.invalid，并附带仅测试用的本机 Key；核心提示词、语音 URL、保存的自定义连接也被替换。没有向该地址真正发请求。 | 备份恢复聊天、角色、记忆与附件；本机 provider/model/baseURL/vision/connections、voiceSettings、coreSystemPrompt 从当前设备保留。准备与恢复路径均做结构校验，界面明确说明。验证内容恢复、Key 接收地址和核心提示词保持当前值。 |
| ZIP 尺寸字段造成限制绕过或静默截断 | 原 unzipSync 按中心目录 originalSize 过滤；声明 1 字节的 2 MiB 存储条目被读取，错误声明的压缩条目仅返回首字母却标记已读取。 | 附件采用流式读取，按实际输出限制每项 1 MiB、总量 8 MiB、最多 40 项；重复已读取名称、不完整条目与本地头尺寸不符均拒绝。中心目录错报不再用于输出缓冲区大小。只在完整恢复实际字节时返回内容；允许返回完整文字而不是错误的截断文字。 |
| 解压检查晚于单次展开 | 原 64 KiB 压缩输入可在回调检查前产生较大的展开缓冲。没有进行耗尽内存或 500 MiB 压力攻击。 | 共用 BoundedZipInflate，256 字节压缩片段交给解码器，输出回调及时检查预算；备份保留原 200 MiB 每项、540 MiB 总展开预算。此处是降低一次解码的内存尖峰，不声称总内存恒定。 |
| 损坏 ZIP 被视为空包 | 换成流式解包后，旧损坏 DOCX 回归发现裸字符串未产生解压错误，被标记没有文字。 | 在解包前检查 ZIP 文件头与完整尾目录，不支持多卷/Zip64；与当前导出器及限额兼容。正常 DOCX、XLSX、ZIP、PDF 和完整 ZIP 备份继续通过，损坏文件诚实报告未解析。 |
| 原生 IP 边界遗漏 | 原 APK 的 allowed 方法实测允许 fd00::1 和 100.64.0.1；测试仅调用地址判断，不实际连接这些地址。 | 补充 IPv6 唯一本地/非全局地址、CGNAT、基准网络及保留范围的拒绝，所有解析结果都必须满足条件，HTTPS 端口只接受默认值或 443。默认公共服务商及自定义公开 HTTPS 功能保留。 |
| 本机网页来源判断缺少端口和 userinfo | 原 shouldInterceptRequest 对 appassets:444 和 user@appassets 都返回 200。这是边界判断证据，不代表已从远程网页取得真实 Key。 | 同一 trustedOrigin 函数检查 HTTPS、精确主机、无 userinfo、默认或 443 端口，用于资源、导航及媒体权限。不正确的本机来源返回 403。明确关闭跨文件和文件跨域访问，保留系统附件选择所需 content access。 |
| 外部 intent 保留任意动作与授权标记 | 静态源码发现 parseUri 后仅清理 component/selector，action 和 flags 仍来自字符串；未声称已成功越权访问。 | 只解析目标数据与可选应用包名，重新创建 ACTION_VIEW；允许普通网页与音乐协议，拒绝 content/file/javascript 等目标，不复制 extras、selector、component 或 URI 授权 flags。本机页面不能经外部入口伪装来源。 |

## 修复与验证顺序

1. 冻结已交付版本及修复前证据，保留现有签名和用户记录。
2. 实施备份保护与实际解压预算，确认正常文件功能；失败时原附件与原记录不被替换。
3. 实施原生地址、精确来源与外部跳转策略，通过本地方法断言；不继续红队突破。
4. 严格类型及全部 103 组具名核心检查、8 套浏览器回归、原生升级/文件选择/Via/本地保存验证。
5. 核对同签名、对齐、CRC 与所有源资源；同步源码、测试、逐文件说明；GitHub CI 通过后再发布。

## 证据说明

`outputs/云笺听雨安全回归-修复前.json` 和 `outputs/云笺听雨原生安全验证-修复前.json` 为停止前已经形成的记录，不补写测试。修复后回归单独记录，测试文件保留旧名称；浏览器报告明确标记注入源辅助库及对应源码摘要，同时记录实际编译资源摘要。原生验证使用同签名测试 instrumentation 调用产品方法，不冒充普通第三方网页或未授权应用的权限。

源码和界面由本轮修改，真实第三方 Key、麦克风通话及物理机未验收。DNS 判断与实际连接仍存在分别解析的结构；本轮没有证明或完全消除 DNS rebinding。Via 二进制与主应用仍共享应用 UID；没有宣称能抵御浏览器原生漏洞、root 或拿到签名私钥的攻击者。以上是未覆盖的结构边界，不算本轮已修复或已利用的缺陷。
