# 0.0.3 rc2 Android 模拟器升级验收

本验收测试固定的已交付签名包，APK SHA-256 为 `295ef6e51a7f953d80e38af827f944c9645a18d07ac9e97fb8e11267c13916e4`，构建来源 `2286321e8b07c59da375dd4169bc11a8fde33bc2`，artifact 11664487240。应用源码不变，本 PR 只增加验收脚本和工作流；不需要为了新增测试重新发行同内容 APK。

工作流下载原 0.0.2 正式独立包和该候选，先校验 SHA-256 与原签名证书，再在全新 Android API 35 / x86_64 模拟器安装旧包。通过真实 UI 写入固定测试纸条、保留未提交编辑草稿，强制结束后读回，然后 `adb install -r` 覆盖安装 0.0.3/10。关闭 Wi-Fi/移动数据，核对纸条和草稿仍存在，再次 force-stop/cold-start 复核。不会卸载或清空数据来绕过升级测试，也不会修改生产 APK 开启调试。

证据仅含固定测试文本、UI XML、截图、安装输出、环境和哈希/签名记录；不输入服务商 Key，不请求付费 API、不恢复用户私有数据、不下载签名密钥备份。

只有实际 workflow 的全部断言通过，才能标记模拟器升级验收通过。若系统镜像 WebView 低于应用要求的 120，则明确失败并记录环境，不将提示框当作正常启动。此测试不证明聊天排队、媒体事务、真实服务商网络/VPN、旧版全部资产或物理设备升级；这些门槛仍由 issue #15 和整合验收报告记录。
