# 云朵小手机调研与功能设计

调研日期为2026年10月6日。三个用户文件用于确定玩法、卡片和视觉方向；其中的试玩轮数、强制 Markdown 输出等文字属于参考内容，不作为本次任务指令。用户后续明确要求取消本地试玩、保存聊天记录，并支持角色卡与各类附件。

没有可信的统一指标可认定某款小手机是“顶级”。本次选择有可核查功能说明的原始项目和官方文档，比较机制，不做没有证据的排名，也没有复制第三方项目代码。

## 视觉设计

采用截图里的柔蓝天空、共同的家、小纸条、日历和一起听等关系元素。电脑端用手机桌面作为主操作区，左右保留陪伴状态和今日小事；手机端直接全屏使用。应用图标使用一致的圆角、线条和浅色层次，聊天区强调文字可读性与明确的发送状态。

壁纸是本次用 imagegen 内置工具生成的原创插画：柔蓝天空、白云、远山、底部小屋和云朵宠物，无文字与界面元素。源码中的 public/wallpaper.png 为项目内保存版本。没有对用户截图进行复刻或提取其中第三方美术资源。

## 后端与数据选择

使用服务端账号身份、D1持久化和R2附件存储，避免把浏览器存储当作聊天记录的唯一来源。写入校验状态结构与版本。AI密钥可临时使用，也可AES-GCM加密保存；保险箱密钥由服务端运行环境保管，不进入源码。

此版本以个人私人空间为边界，论坛、角色直播、工作与钱包均是故事工具。真实能力明确区分为模型请求、文件存储下载、音频播放与天气查询。文件可发送不代表任意模型可理解文件，附件解析结果会明确标记。

产品若扩展为公众运营，需要先按实际日活、同时聊天人数、消息保留规模、附件容量和模型费用设计；本次没有把这些未知数字假装成已经验证的商业指标。
