# 最终改进与验证

计划：先完成真实模型发现、连续性摘要、语音和音乐；再接入情绪桌宠；最后检查协议、安全边界、持久化、视觉和构建，并发布同一个私人网址。

## 实现

- 模型：填写 Key 后自动读取服务商列表；Custom 自填 HTTPS URL、Key、模型名。列表读取失败保留明确错误，手填仍可用。
- 记忆：固定角色卡前缀、相关记忆检索、旧对话原文检索、默认每32条阶段摘要。检索使用中文双字和英文词匹配，不冒充向量语义检索。阶段摘要可查看、编辑和删除，按真实消息游标推进。
- 防复述：比较最近四条角色回复，检测高度相似时最多重写一次；保留各供应商适用的采样参数。第二次仍可能重复，不能保证绝不重复。
- 缓存：动态时间、摘要、召回和背景放在尾部；历史按固定批次选择。实际命中统计来自服务商返回用量，未报告时不虚构命中率。
- 3D桌宠：原创程序化云朵模型、物理材质、柔光、六种表情与动作、对话气泡；30fps上限、像素比1.5上限，后台、离屏和首页被应用覆盖时停止渲染，卸载释放资源。不支持WebGL时显示插画。
- 音乐：真实本机音频播放器，LRC/TXT导入；对话栏显示导入歌词原文，LRC按播放与拖动同步。点击沉醉桌宠生气。无歌词显示欣赏词。外部音乐有网易云和自选链接；无法读取外部播放器进度或歌词。
- 语音：设备朗读、OpenAI TTS、兼容 /audio/speech 接口，支持试听、停止、语速、自动朗读；聊天与TTS可使用不同供应商。Realtime通过OpenAI WebRTC接口获取和播放真实音频，麦克风由浏览器授权，转录保存到本地。
- 数据与界面：保留本机记录、附件、独立加密Key、完整ZIP备份。默认浅色，夜色使用低眩光蓝灰。首页保持四个应用入口与留白。

## 验证范围与限制

上述API响应使用协议测试数据；没有你的真实Key，没有完成真实供应商账单、音质或Realtime通话实测。后台摘要和一次防重复重写会增加调用；可在设置关闭。不承诺长期记忆零遗忘或性格绝不漂移。当前是私人网页应用，未生成APK；Source Serif 4本地打包，中文使用中文衬线回退，因为该字体不包含汉字。
