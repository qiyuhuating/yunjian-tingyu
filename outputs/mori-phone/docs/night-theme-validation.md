# 暗夜主题调整

参考 [SillyTavern Dark Lite 默认配置](https://github.com/SillyTavern/SillyTavern/blob/release/default/content/settings.json) 的深灰底、暖白字与无文字阴影思路，针对云朵小手机独立调整。没有复制整套CSS或改变字体、功能、默认浅色模式。

色彩：画布 #151719，阅读背景 #1b1d20，卡片 #242629，正文 #eeeae2，辅助字 #b9b9b3，淡蓝强调 #c2d8e8。首页卡片与桌宠对白不透明；壁纸保留少量景观轮廓。用户消息使用低饱和蓝灰区分。输入框、导航、底栏、侧栏、设置、音乐、日记与桌宠采用统一层级。

验证：生产构建通过。浏览器检查首页、聊天、设置的10处关键文本，实测前景/不透明背景对比度7.13至14.08；文字阴影均为none，Source Serif 4声明保持。320、390、768、1440宽度无横向溢出，无页面异常。已查看手机截图。对比度检查针对列出的关键文本，不代表完整无障碍认证；字形渲染仍取决于设备与中文回退字体。
