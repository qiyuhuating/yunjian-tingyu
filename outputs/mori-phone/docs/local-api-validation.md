# 本机存储与多服务商：计划 → 执行 → 验证

核对日期：2026-10-06。最新用户要求覆盖此前云端记录方案：记录和原附件保存在设备，继续使用真实联网 AI，多服务商预设只填 Key，保留重复惩罚设置。

## 计划与成功条件

1. 核对 Tavo 及官方接口文档 → 普通服务商无需填写地址和模型；不把不支持的惩罚发送到接口。
2. 将数据迁入账号隔离的 IndexedDB → 刷新保留记录、草稿、附件；正常保存不调用云端状态写入或上传。
3. 将 Key 按服务商保存在设备 → 切换不会误用另一家 Key；完整备份不含 Key。
4. 适配 OpenAI、Claude、Gemini 协议 → 正确处理流式正文、结束、取消、用量、缺失缓存字段。
5. 验证迁移、备份、故障与布局，构建并发布到现有私人 Site → 保留账号和受众，不改公开分享。

## 执行结果

- `local-phone.ts`：账号分区的设备状态、Blob 附件、草稿和版本校验。Key 使用设备上的非导出 AES-GCM CryptoKey 加密，按账号和服务商绑定；同源应用在请求时能够解密，不能把它理解成隔离于本应用的硬件保险箱。
- 首次打开先读取旧版存档，完整迁入所有旧附件和旧 Key，再发布本机状态；失败时保留旧记录并提供重试。成功后的打开不再拉取旧状态。旧云端副本留作过渡档案，新记录与新文件只存本机；设置提供导出 ZIP 后清理旧副本的入口。
- 本机附件单个不超过 200 MB，容量受设备空间约束；移除原来的 150 MB 云端配额和角色导入 1.85 MB 状态请求限制。安全的图片、音频可预览，HTML/SVG 等文件保留字节、使用下载 MIME。
- `local-backup.ts`：完整 ZIP 包含当前记录引用的原附件及 SHA-256 清单，不含 Key；单包附件总量最多 512 MB。恢复先校验所有文件，使用新附件 ID，避免覆盖现有文件；兼容旧 JSON 的记录导入。
- 十家预设：DeepSeek、OpenAI、Claude、Gemini、OpenRouter、硅基流动、通义千问、Kimi、智谱、xAI；另有自定义 HTTPS OpenAI 兼容接口。推荐模型和地域见[官方来源调研](provider-presets-research.md)。模型列表可读取，手动模型 ID 放在高级连接中。
- 请求只包含当前角色、选取的历史、相关记忆、命中世界书和显式允许的图片；不上传整个数据库和日记。私有网关临时转发并统一原生流式事件，不保存聊天、上传文件或 Key；服务商自身的数据政策另行适用。旧存档读取/清理与每分钟请求计数仍使用原 D1/R2。
- 保存所有采样数值，按能力发送。百炼发送 presence/repetition，硅基发送 frequency，DeepSeek 与 Claude 不发送无效惩罚。OpenRouter 开启惩罚时要求后端实际支持。OpenAI 使用 `store:false` 和 `max_completion_tokens`；Claude 稳定系统和历史块使用原生缓存断点。
- 首页留白、手绘主按钮、底栏、小云和 Source Serif 4 字体资源保持原设计。设置重排为服务商、Key、折叠高级连接/采样、设备备份，中文继续使用衬线字形回退。

## 验证证据

- `node scripts/verify-core.mjs`：18 项核心场景，包括稳定前缀、世界书、角色卡导入保真和损坏文件拒绝。
- `node scripts/verify-providers.mjs`：17 项适配场景，包括十家请求结构、原生图片/鉴权、惩罚矩阵、UTF-8 分片、缓存用量、断流/取消、迁移字节编码。
- 浏览器主流程：16 项，包含设备持久化、Key 切换隔离/加密、聊天流式落盘、草稿、图片/ZIP/TXT 原件、跨设备完整 ZIP 恢复、损坏包拒绝、旧记录/Key 迁移、失败重试、双窗口冲突。正常流程只进行 1 次首次旧状态检查，云端状态写入和附件上传均为 0。
- 浏览器故障流程：5 项，包含 IndexedDB 事务失败时内容保留、故障期间完整备份、重试落盘、账号读取隔离、不可信 MIME 降级。
- 开发环境旧档案实测：34 个旧附件全部迁入；逐个对比来源与本机 Blob 的 SHA-256，34/34 一致。空下载响应会改用流式 JSON 迁移通道重试，大小仍必须吻合，不把空响应当成功。
- 24 个应用打开检查；320、390、768、1440 四视口无横向溢出，主屏 8 个图形和启动器 7 个手绘图形居中；390×844 底栏完全可见。页面错误为 0。
- TypeScript 含未使用变量检查、生产构建：通过。

本轮未收到用户真实服务商 Key。AI 响应采用协议夹具验证；不宣称已测量付费模型回复质量、所有真实账号连通性、服务商缓存命中率或商业负载。
