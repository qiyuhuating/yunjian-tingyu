# 云朵小手机使用说明

这是供你个人使用的私人网页应用。电脑打开时是一张小手机桌面，手机打开时采用全屏布局。网页可添加到手机主屏幕。此次交付的是网页应用与完整源码，没有生成 Android APK。首页默认使用浅色云朵蓝主题；月光夜主题改为低眩光深蓝灰层级，可在设置里切换。

首页保留一排聊天、论坛、浏览器、日记。右上角“全部应用”可打开其余功能；小云与对白气泡可点击进入桌宠页面。底栏仍为首页、日历、记忆、设置。

## 第一次打开

1. 用创建此应用的 ChatGPT 账号登录。
2. 打开设置，修改你的名字、角色对你的称呼和生日。称呼可以是主人，也可以是任意昵称。
3. 打开设置选择服务商预设，填写对应 Key，点“保存连接”。常规预设已配好地址和推荐模型；不需要自己填接口地址。可选 DeepSeek、OpenAI、Claude、Gemini、OpenRouter、硅基流动、百炼、Kimi、智谱、xAI。高级连接可读取模型列表、换模型或填写自定义 HTTPS 兼容接口。
4. Key 按服务商分别加密保存在本机，下次打开无需重填；切换服务商会自动读取各自 Key。Key 不进入 ZIP 备份。测试真实连接会进行一次真实 AI 调用；账号需要对应地区、模型权限和额度。
5. 在角色设定中编辑默认角色，或导入自己的角色。新增原创角色云汐和参考文档的14位角色只是可编辑的起点。

界面主字体固定采用随包提供的 Source Serif 4；中文字符按系统可用的中文衬线字体回退，以保证每台设备都能完整显示汉字。主屏和“全部应用”的功能入口使用同一套手绘透明按钮素材，桌宠插画与字体都在网页资源内，不依赖外部字体 CDN。

没有本地预设回复，没有20轮试玩限制。未连接 AI 时，自己的消息仍可保存，但不会生成角色回复。角色首次见面时的问候语属于角色卡内容，可以自行编辑。

## 导入角色

| 格式 | 行为 |
| --- | --- |
| TXT | 文件名作为初始姓名，正文作为人设 |
| JSON | 识别常用 V1、V2、V3 结构，读取姓名、人设、性格、场景、开场白、示例对话和补充设定 |
| PNG 角色卡 | 读取 chara 或 ccv3 元数据，包括 tEXt、zTXt、iTXt 文本块，并保存头像 |
| 普通 PNG | 作为头像导入，人设由你补充 |

角色卡单个不超过4 MB，先显示导入预览，再确认写入。可选择备选开场白；遇到同名角色可新增副本，或更新设定并保留聊天。可选导入内嵌世界书，保留停用条目、常驻背景、主次关键词、排列顺序和角色范围。支持后置指令、作者与标签；未知扩展保留用于导出，不执行第三方扩展。

历史按32条分段选取、最多64条，并受设置中的历史字符预算约束（默认24000字符）；超长单条内容会标记截断。最近12条可见记忆、最多12条世界书和8000字符背景独立计入上下文。动态时间、记忆与背景置于历史之后，减少破坏固定前缀。V3媒体资产、递归世界书、脚本与酒馆自定义插入位置不在执行范围。

设置里的高级对话参数可控制变化、思考模式、回复上限与历史预算；所有重复、频率、存在惩罚的设置均保留；界面按当前接口能力禁用无效字段，请求仅发送支持的参数。百炼支持 presence/repetition，硅基支持 frequency，OpenRouter 和自定义接口视模型支持而定。当前官方 DeepSeek 已弃用频率/存在惩罚，因此不发送这些无效字段。实时缓存用量面板显示提供方返回的 token 与首字等待，只在本次打开页面累计，字段缺失时显示未返回。

聊天草稿会在停止输入约0.8秒后保存到本机，跨导航和刷新保留；保存完成前关闭页面仍可能丢失最近输入。阅读旧消息时不自动抢走滚动位置，可点击回到最新消息。停止或断流会保留已收到的部分回复。手机端保存失败时可导出本页备份并重试；版本冲突需要先备份再读取设备记录。

## 聊天与附件

聊天支持单聊、群聊、长短消息视图、表情、可朗读语音卡片、收藏、记忆、删除、导出、真实 AI 流式回复、重试和中止。群聊每次默认邀请前三位成员发言；使用 @角色名字 可以指定群成员。

点回形针可发送多个附件，包括图片、GIF 表情包、TXT、JSON、Word、PDF、ZIP、RAR 及其他文件。每批最多6个，每个不超过200 MB，总量受本机设备空间约束。附件原文件保存到本机数据库，聊天中保留下载入口。移除相册条目不会删除聊天里引用的原文件。

- TXT、Markdown、CSV、JSON、LOG 文件在256 KB以内会提取最多18000个字符。
- DOCX 在20 MB以内才解析，且只读取 word/document.xml 的文字，限制其解压后大小为1 MB，并提取最多18000个字符；复杂排版、图片、表格格式不会还原。
- 图片输入需要在设置中启用，并且模型本身支持视觉；最近两张小于等于4 MB的图片可进入上下文。更大的图片仍可发送、保存和下载。
- PDF、旧版 DOC、PPT、压缩包等可发送保存，但当前不自动解析其内容。压缩包不自动解压。AI 不会被告知这些未解析附件已被读懂。
- 所有文本按文字显示，不执行附件或角色卡中的 HTML、JavaScript；角色人设与后置要求仅用于模型提示词。

## 保存与恢复

聊天、草稿、角色、日记、记忆和原附件保存在当前设备 IndexedDB，按账号分区。写入使用设备事务和版本检查，另一窗口更新时不会悄悄覆盖。保存失败保留本页内容，先导出完整 ZIP，再重试或读取设备记录。

完整 ZIP 包含记录与当前记录引用的原附件，以及 SHA-256 校验清单，不包含 API Key；可恢复到新设备。旧 JSON 可导入记录，但其附件必须能从本机或原站点找回。每个会话最多3000条记录；完整 ZIP 的附件总量最多512 MB。AI 回复需要联网；网页启动仍需要账号登录，浏览器关闭后不提供后台闹钟。

## 放到手机桌面

- Android Chrome / Edge：打开网站，浏览器菜单中选择安装应用或添加到主屏幕。
- iPhone Safari：打开网站，分享菜单中选择添加到主屏幕。

该应用具备 Web App Manifest 和安装图标。能否显示安装提示取决于浏览器与平台登录流程。

## 本机记录与备份

记录和原附件仅保存在当前设备，换设备需导出完整 ZIP（不含 Key）。清除站点数据会删除本机记录。首次打开先完整迁入旧记录、原附件和旧 Key，失败会保留旧记录供重试。导出完整 ZIP 后，可在设置清理旧云端记录、附件与 Key 副本；新聊天与新文件只在本机保存。完整 ZIP 附件总量最多512 MB。AI 请求经私有临时网关发送到选定服务商，不在网关持久保存。

## 本轮新增使用方式

填写Key会自动读取实时模型列表，Custom可填写自己的地址和模型ID。长期记忆与对话连续性中可设置摘要间隔、关闭召回或防重复重写；摘要与重写需要额外模型调用。声音设置可选设备、OpenAI或兼容TTS，保存语音Key后试听；聊天电话入口另有OpenAI Realtime，需要具有权限的Key和麦克风许可。

一起听可上传本地音频，再导入LRC歌词，桌宠气泡会显示实际歌词原文并跟随播放。网易云与自选音乐在外部打开；外部播放进度不会同步到本页面。桌宠现在有真实3D模型和六种情绪，点击一起听中的桌宠会生气。

语音与实时通话尚未使用你的真实Key实测。完整验证范围见《最终改进与验收.md》。
